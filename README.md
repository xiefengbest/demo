# AnyWP 数据 Demo

AnyWP 用户数据后台方案，页面数据为演示值。

## 发布版本

- V1（原数据维度）：`/demo/v1/`，保留原版日活、事件、版本和地域分析。
- V2（用户维度）：`/demo/v2/`，按“日活与新增、地域分析、产品详情”组织。
- V3（精简地域分析）：`/demo/v3/`，地域页包含活跃分布图和用户明细。
- V4（地域明细）：`/demo/v4/`，地域页仅保留筛选和地域用户明细。
- V5（精简产品详情）：`/demo/v5/`，详情按 Firebase 用户维度展示。
- V6（厂商权限）：`/demo/v6/`，Publisher 对应后台厂商；提供平台管理员与厂商账号的权限范围预览。
- `/demo/` 根路径始终指向当前最新版本（目前为 V6）。

各版本中的明细数据均为演示值。V6 的身份切换仅模拟界面范围，正式权限应由现有后台账号授权并在服务端接口校验。
